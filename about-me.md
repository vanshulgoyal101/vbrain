- **Build in public** — a devlog, screenshots, and honest post-mortems.
- Prefer **boring, durable tech** and tiny dependency trees.

## Why this file exists

Every note in a vbrain brain follows the same shape (an `# H1`, a `> TL;DR`
blockquote, then short sections). That consistency is what lets the engine —
search, the graph, the MCP server — treat the whole thing as one queryable
knowledge base. See [CONVENTIONS.md](CONVENTIONS.md).
