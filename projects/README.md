## How project notes work

Each project note records the **stack**, **architecture**, **what shipped**, and
the **gotchas** worth remembering — so future-you (or an AI agent) never
re-derives context. The reusable lessons get promoted to
[learnings/](../learnings/README.md).

## Principles

- Ship small, ship monthly. A shipped beta beats a perfect plan.
- Write the post-mortem even when it works — that's where the lessons hide.
- Keep the dependency tree tiny; prefer the platform over a framework.
